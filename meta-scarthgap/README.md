# meta-scarthgap

Scarthgap BitBake 2.18 compat layer

To use `bitbake-setup` requires `bitbake` 2.9 or newer. We use `bitbake` 2.18 as
it is the LTS version used in Wrynose.

Scarthgap is shipped with `bitbake` 2.8, which is incompatible with `bitbake` 2.18.
This layer is intend to shim the difference.
